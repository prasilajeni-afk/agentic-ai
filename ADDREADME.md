# Fake News Detection Using NLP

## 📌 Project Description
This project detects whether a news article is Fake or Real using Natural Language Processing (NLP) and Machine Learning techniques.

## 🎯 Objective
- Detect potentially fake news.
- Analyze news text using NLP.
- Classify news as Fake or Real.

## 🛠️ Technologies Used
- Python
- Natural Language Processing (NLP)
- Machine Learning
- TF-IDF

## ⚙️ How It Works
1. User enters a news article.
2. The text is preprocessed.
3. NLP techniques are applied.
4. The model analyzes the text.
5. The system predicts Fake News or Real News.
